Getting started

Build an AI reviewer that catches dangerous software changes. Submissions must pass the quality gate, and the lowest cost measured by Merge Gateway wins.

No account is required to begin. The starter and public benchmark run locally, make zero model calls, and cost nothing.

What you are building

Your submission implements one Python function. It receives a pull-request case containing a diff, issue, repository context, CI logs, migrations, dependencies, and prior discussion. It returns an evidence-backed release review. 

from costhack.schema import Case, ModelClient, Review

def review(case: Case, client: ModelClient) -> Review:
    ...

You may use deterministic rules, the evaluator-provided model client, or both. You may also build your own Merge Gateway client and optionally use condense.chat to preprocess model inputs. The final evaluator uses harder private cases. All scored model inference must run through Merge Gateway so its cost can be measured consistently.

1

Set up the sponsor accounts

You can skip this section until you want to make live model calls. If the event gives you credentials, use those instead of creating separate ones.

Merge Gateway

New Merge Gateway accounts include $10 in free credit. You can use this credit for model calls during the hackathon.
  1. Open gateway.merge.dev/signup.
  2. Create an account and complete verification.
  3. Accept the event organization invitation if you receive one.
  4. Open Settings → API keys.
  5. Create a regular model-calling key beginning with mg_.
  6. Copy the event project ID. Do not use an mgmt_ management key.

condense.chat

  1. Install the official CLI:
curl -fsSL https://cli.condense.chat/unix | sh
  1. Start the browser sign-in flow:
dense login
  1. Choose Sign up if you do not have an account.
  2. Complete the device flow, then verify:
dense status
dense doctor
  1. If you need direct API access, copy the ak_ token from the condense.chat dashboard.

Store credentials locally

cp .env.example .env
chmod 600 .env

Edit .env:

MERGE_GATEWAY_API_KEY=mg_replace_me
MERGE_GATEWAY_PROJECT_ID=replace_me
CONDENSE_AUTH_TOKEN=ak_replace_me
Never commit .env. If a secret is committed, revoke it immediately. Removing it from the latest commit does not remove it from Git history.
2

Install the prerequisites

You need:

  • Git
  • Python 3.11 or newer
  • uv

Check them:

git --version
python3 --version
uv --version
3

Clone the starter

git clone https://github.com/kaashif/ai-cost-hack.git
cd ai-cost-hack
uv sync

This installs the benchmark CLI and development tools from the committed lockfile.

4

Run the public benchmark

uv run costhack benchmark --public

The deliberately incomplete starter should report:

NOT ELIGIBLE  quality=50.0  model_calls=0
Public cost is $0.00 because the starter strategy is local.

The starter catches five of ten cases. The examples demonstrate the input, output, and scoring contract without revealing the final test set.

5

Inspect a public case

uv run costhack inspect public-auth-delete

Read data/public_cases.json to see the complete public case schema. Public cases include their rubrics; private cases do not.

6

Edit your strategy

Open submission/strategy.py. Keep the review(case, client) entry point and return this shape: 

{
    "risk": "high",
    "findings": [
        {
            "category": "authorization",
            "severity": "high",
            "file": "api/delete_project.py",
            "evidence": "The project is loaded without an owner check.",
            "explanation": "A user can delete another tenant's project.",
        }
    ],
    "tests": ["Cross-tenant deletion must return 403"],
    "next_action": "block",
}

If you use a model, call client.generate(...). Do not create another paid provider client. 

response = client.generate(
    model="openai/gpt-5.5",
    messages=[
        {"role": "system", "content": "Review this change."},
        {"role": "user", "content": case["brief"]},
    ],
    max_output_tokens=1200,
    compression="none",
    tags={"stage": "review"},
)

There are two complete starting points: submission/strategy.py contains the deterministic Python rules baseline, and examples/merge_only/strategy.py contains the GPT-5.5-through-Merge strategy.

Once quality is reliable, consider condense.chat for long, noisy cases. Compare compressed and uncompressed inputs with the same prompt and GPT-5.5 model. You can use Condense's Rewrite API, but send the resulting model request through Merge Gateway so its cost is included in the official measurement.

7

Validate your submission

uv run costhack preflight
uv run costhack benchmark --public
uv run pytest
git status --short

Confirm that .env is ignored and that your public benchmark still passes after every strategy change.

8

Commit, push, and submit

git add submission pyproject.toml uv.lock
git commit -m "Submit PatchGuard strategy"
git push
git rev-parse HEAD

Submit both of these before the cutoff:

  • Your public GitHub repository URL
  • The exact commit SHA printed by the final command

Scoring

Scoring happens in two stages:

  1. Pass the quality gate. Your reviewer must catch the required dangerous changes on the private benchmark. Cost is considered only for submissions that pass.
  2. Rank by Merge Gateway cost. Among passing submissions, the winner is the entry with the lowest total model cost recorded by Merge Gateway during the official benchmark run.
Merge Gateway is the source of truth for cost. We do not score local estimates, raw token counts, provider price tables, or costs reported by participant code. Deterministic local computation adds no model cost; every scored model request must appear in the official Merge Gateway usage record.

Rules

All scored model inference must run through Merge Gateway. Optional preprocessing, including condense.chat, does not replace this requirement.
